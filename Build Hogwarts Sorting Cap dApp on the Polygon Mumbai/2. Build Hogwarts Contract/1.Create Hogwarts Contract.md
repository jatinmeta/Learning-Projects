## Writing the Smart Contract

Our contract will:
- Allow the owner to mint NFTs representing Hogwarts houses.
- Store NFT metadata on IPFS.
- Ensure NFTs are **soulbound** (non-transferable) within Hogwarts.

So, let’s get started!

### License and Imports

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.8;

import "@openzeppelin/contracts@4.8.0/token/ERC721/extensions/ERC721URIStorage.sol";
import "@openzeppelin/contracts@4.8.0/access/Ownable.sol";
import "@openzeppelin/contracts@4.8.0/token/ERC721/ERC721.sol";
```

These imports provide:
- `ERC721URIStorage`: Adds metadata storage to ERC-721 tokens.
- `Ownable`: Ensures that only the contract owner can mint NFTs.
- `ERC721`: Implements the ERC-721 NFT standard.

### Contract Definition

```solidity
contract HogwartsNFT is ERC721URIStorage, Ownable {
```

### Functions

#### Check if User Has Minted an NFT
```solidity
function hasMintedNFT(address _user) public view returns (bool) {
    return hasMinted[_user];
}
```

#### Get User’s House
```solidity
function getHouseIndex(address _user) public view returns (uint256) {
    return s_addressToHouse[_user];
}
```

#### Mint an NFT
```solidity
function mintNFT(address recipient, uint256 house, string memory name) external onlyOwner {
    require(!hasMinted[recipient], "You have already minted your house NFT");

    uint256 tokenId = s_tokenCounter;
    _safeMint(recipient, tokenId);
    _setTokenURI(tokenId, houseTokenURIs[house]);

    s_addressToHouse[recipient] = house;
    s_addressToName[recipient] = name;

    s_tokenCounter += 1;
    hasMinted[recipient] = true;

    emit NftMinted(house, recipient, name);
}
```

#### Restrict NFT Transfers (Soulbound NFTs)
```solidity
function _beforeTokenTransfer(address from, address to, uint256 firstTokenId, uint256 batchSize) internal virtual override {
    super._beforeTokenTransfer(from, to, firstTokenId, batchSize);
    require(from == address(0) || to == address(0), "Err! This is not allowed in Hogwarts");
}
```

## Deploying the Contract

### Step 1: Open Remix IDE

Head to [Remix](https://remix.ethereum.org/) and create a new Solidity file `HogwartsNFT.sol`.

### Step 2: Compile the Contract
- Click on the **Solidity Compiler** tab.
- Select `0.8.8` as the compiler version.
- Click **Compile HogwartsNFT.sol**.

### Step 3: Deploy on Arbitrum Sepolia Testnet
1. Go to the **Deploy & Run Transactions** tab.
2. Select **Injected Provider - MetaMask**.
3. Choose **Arbitrum Sepolia** network in MetaMask.
4. Click **Deploy** and confirm the transaction.

🎉 Congratulations! You’ve successfully deployed your Hogwarts NFT contract!
